# MediMitra Care

> **Apki Dawaiyon Ka Dost** — your medicine's best friend. Snap a strip, catch
> a dangerous interaction, and never miss a dose. Built for India's elderly and
> the adult children who worry about them.

![MediMitra Care brand illustration](./public/brand.svg)

MediMitra Care contributes to **UN SDG 3 — Good Health and Well-being** by
closing the single biggest preventable gap in Indian elderly healthcare:
medication safety. A hand-held, bilingual, pictogram-first companion that
turns one photo of a medicine strip into an identification card, an FDA-grade
safety check, a daily schedule, and a caregiver share link.

---

## Demo summary (60 seconds)

1. Open the live URL on a phone and land on a bright Bharat-accent home
   screen with three big cards: **Scan · Schedule · Safety**.
2. Tap **Scan My Medicine**, then tap the `Crocin Advance` demo strip. In
   about 3 seconds a flip card announces:
   `Paracetamol 500 mg · Pain & Fever · Max 4 tablets/day`.
3. Tap **Add to my pills**. A **moderate-interaction** banner slides up:
   `with Warfarin (already in your list) — may increase bleeding risk —
   source: openFDA`.
4. Jump to **Schedule**. The new pill appears under a sun/moon pictogram.
   The 🔊 *Read aloud* button speaks `"Aaj subah 8 baje Paracetamol lena
   hai"`. One tap opens a WhatsApp share sheet for the caregiver.
5. Pitch line: *All data is FDA-sourced, every API is free-tier, and the
   whole app runs in Docker in under 60 seconds.*

- **Caregiver share link** at `/caregiver/[token]` — no login, pure URL-based
  payload, generated by `backend/services/caregiver_link.ts`.
- **Voice mode (Hindi + English)** powered by the Web Speech API, triggered
  from the Schedule page.
- **Polypharmacy risk score (0–100)** with three "talk to your doctor"
  points — see `backend/services/interaction_engine.ts` +
  `ml/risk_classifier.ts`.

## Architecture

![Architecture overview](./public/architecture.svg)

A deliberately simple monorepo — no microservices, no server DB, no hidden
state.

```
medimitra-care/
├─ app/                     Next.js 14 App Router entrypoints and API routes
├─ frontend/                Client-only UI kit, layout, state (Zustand)
│  ├─ components/ui         Buttons, cards, badges, toast, modal, input
│  ├─ components/layout     Top nav, tab bar, footer, hidden-judge notice
│  ├─ components/{home,scan,schedule,safety,ask,settings}
│  ├─ lib/                  cn() helper, api_keys_storage, browser utilities
│  └─ state/                Zustand patient store (localStorage-backed)
├─ backend/                 Pure-TS services reachable from app/api/*
│  └─ services/             rxnorm · openfda · gemini · interaction_engine …
├─ ml/                      Rule-based NER, OCR fallback, risk classifier
├─ data/                    Seed catalogues (Indian medicines, DDI, label cache)
├─ scripts/                 Dev utilities (verify_demo_data)
├─ tests/                   Node --test unit tests for core logic
├─ public/                  Brand + architecture SVGs, favicon
└─ Dockerfile               Multi-stage build → minimal Node runtime
```

The browser is the only place any personal data lives — every medicine you
add is stored in `localStorage` and gone as soon as you clear the site.

### Data flow for a single scan

1. `frontend/components/scan/scan_experience.tsx` posts the image or demo
   hint to `app/api/scan/route.ts` with any `x-user-*-key` headers.
2. `backend/services/gemini_service.ts` calls Gemini 2.5 Flash or falls back
   to a deterministic demo result.
3. `backend/services/openfda_service.ts` fetches the FDA label (or pulls
   the bundled cache from `data/openfda_label_cache.ts`).
4. `backend/services/interaction_engine.ts` cross-checks against the user's
   current list using the DrugBank-derived table in
   `data/drug_interactions.ts`.
5. The route returns a single `ScanResult` JSON; the UI animates the flip-
   card and the color-coded banner.

## Tech stack

- **Framework:** Next.js 14 (App Router) · TypeScript 5
- **UI:** Tailwind CSS 3.4 · hand-rolled shadcn-flavoured primitives
- **State:** Zustand 4 with `persist` middleware (localStorage)
- **LLM / vision:** Google Gemini 2.5 Flash (multimodal) via the free
  Generative Language API
- **Drug data:** RxNorm REST API (NLM) · openFDA Drug Label API · DrugBank
  DDI public dataset (bundled locally)
- **Voice:** Web Speech API (`speechSynthesis`), languages `hi-IN` and
  `en-IN`
- **Containerisation:** Multi-stage Node 20 Alpine, Next.js `standalone`
  output, non-root runtime user

Every external call has a graceful offline fallback — the 60-second demo
works with the network unplugged.

## API keys

MediMitra Care runs in **demo mode** out of the box — no keys required, no
broken screens. To switch to live Gemini scanning and FDA label fetching,
open `/settings` in the app and paste any of the following free-tier keys:

| Key name      | Why we use it                          | Get one                                         |
| ------------- | -------------------------------------- | ----------------------------------------------- |
| Gemini        | Multimodal scan + conversational Q&A   | https://aistudio.google.com/apikey              |
| openFDA       | Higher rate limit on label calls       | https://open.fda.gov/apis/authentication/       |
| Hugging Face  | Optional DrugBank DDI refresh          | https://huggingface.co/settings/tokens          |

Keys live in your browser's `localStorage` under a single namespaced
`medimitra_api_keys` entry. They are forwarded on a per-request basis via
`x-user-*-key` headers and never written to disk or logged on the server.

## Research that grounds the product

- **Apte et al., 2025** — *Evaluation of acceptability and feasibility of
  using manual pill organizers and pill reminder apps for improving
  medication adherence among elderly population from rural Maharashtra*,
  KEM Hospital Research Centre. Documents the 40–75% non-adherence rate
  and the gap in Indian-context apps.
- **PMC, 2021** — *Issues and challenges of polypharmacy in the elderly:
  a review of contemporary Indian literature*. Establishes polypharmacy
  as a leading driver of ADRs, falls, and mortality in Indian elders.
- **openFDA Drug Label API** — public, quarterly-updated, no key required,
  used for regulatory-grade warnings.
- **RxNorm / RxNav (NLM)** — free, keyless, 20 req/s, used for consistent
  brand → ingredient normalisation.
- **DrugBank DDI Hugging Face dataset** — source for the bundled
  interaction table.
